Teleprompter

Use two devices: one controls the script, the other is the screen the talent reads from. Both need an internet connection.

🎛 Controller Run the script, speed, settings and library from this iPad, phone or laptop. Sign in with Google.
📺 Presenter window Show the scrolling script on this device. No sign-in needed — just enter the code from the controller.

Using a desktop computer with a second monitor? Use the desktop version
